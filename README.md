## 我的项目

### [MaaXA](https://github.com/AkumaYUC/MaaXA)

基于 MaaFramework 的金蝶云自动化办公助手，支持图像识别驱动的单据录入、任务归档与过期清理。

搭配 MFAAvalonia GUI 框架，提供拖拽式的批量任务入口与运行日志。
